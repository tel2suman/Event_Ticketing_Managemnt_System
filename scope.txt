Here is the full breakdown, MongoDB schema design, and DFD/ERD plan for the Event Ticketing & Management System using MongoDB.

🧠 Project Overview – Event Ticketing & Management System
An online platform where:
•	Users can browse events and purchase tickets
•	Admins can manage events, pricing, and validate tickets using QR codes
•	System manages payment flows and ticket generation/delivery

🧩 Functional Modules
👥 Users
•	Browse events
•	Purchase tickets with online payment
•	View/download QR-coded tickets
•	Manage upcoming/past ticket purchases

🛠️ Admin
•	Create/manage events and ticket pricing tiers
•	Activate/deactivate events
•	Scan QR tickets (check-in validation)
•	Track ticket sales and event analytics

🔁 DFD Flow Summary
•	Admin → Create Events & Pricing → events, ticket_tiers
•	User → Browse Events → events
•	User → Purchase Ticket → tickets, payments
•	System → Generate QR Code → tickets
•	Admin → Scan QR at entry → updates tickets.checkedIn = true
